# 2026-06-12 手机端首页修复

## 背景

最新版首页在手机端首屏信息过重，顶部搜索框与导航纵向堆叠后挤占主界面空间。首页介绍也偏长，不利于移动端快速理解。

## 改动范围

- 缩短首页 hero 介绍文案，保留河源中学、校友经验、提问与回答的核心信息。
- 手机端隐藏 header 内的搜索框，保留导航中的“搜索”入口。
- 手机端 header 改为更紧凑的品牌 + 横向滚动导航布局。
- 收紧手机端 hero 间距、按钮尺寸、标题字号和母校信息块间距。

## 验证

- 已运行 `npm run build`，构建通过；本次构建输出 25 个页面。
- 已本地预览 390px 手机宽度，确认首屏无明显挤压、溢出或遮挡。
- 已运行 `npm audit`，结果为 0 个漏洞。
