# 2026-06-12 首页交互分布与母校定位

## 背景

本次根据网站主要面向河源中学学生与校友的定位，调整首页首屏表达和交互入口。目标是让读者进入网站时更快理解：这是一个从河源中学出发、由校友共同补足大学与高中信息差的内容站。

## 改动范围

- 首页首屏文案加入“河源中学”“河中”“学弟学妹”“毕业校友”等母校身份信号。
- 首屏行动入口重排为：
  - 看问答
  - 搜索内容
  - 浏览文章
  - 我要投稿
- 首页右侧信息块改为母校身份与站点概览，展示当前文章数和问题数。
- 在首页前置问答预览区，突出“从问题出发找信息”的新使用路径。
- 调整主要分类说明，让“问题回答”自然融入升学、专业和生活内容体系。

## 设计取舍

- 不使用河源中学校徽、校门照片或官方素材，避免素材版权和授权问题。
- 不新增图片依赖，也不改变现有内容模型。
- 保持浅白暖色调和现有卡片系统，只通过文案、信息层级和轻量样式强化身份感。

## 验证

- 已运行 `npm run build`，首页、问答、文章和搜索构建通过；本次构建输出 25 个页面。
- 已本地预览首页桌面宽度，确认首屏母校定位、四个行动入口和问答预览区展示正常。
- 已本地预览 390px 移动宽度，确认按钮换行、母校信息块和统计信息无明显溢出。
- 已运行 `npm audit`，结果为 0 个漏洞。
