# 2026-06-11 多选标签筛选与首页定位文案

## 背景

本次迭代修复搜索页标签筛选只能单选的问题，并处理点击标签后出现“筛选搜索失败，请稍后重试”的 bug。同时调整首页介绍，让网站定位从偏严肃的升学资料库，扩展为帮助高中生理解大学真实处境、打破大学和高中信息差的校友分享站。

## 改动范围

- 搜索页标签筛选从单选改为多选。
- 多标签筛选使用 Pagefind 的 `all` 过滤逻辑，只有同时包含所有已选标签的文章才会出现。
- 修复 Pagefind 筛选 API 调用方式：
  - 无关键词筛选使用 `pagefind.search(null, ...)`。
  - 通过动态 `import("/pagefind/pagefind.js")` 获取 Pagefind API。
- 增加标签筛选状态提示和“清空”按钮。
- 修复多选结果卡片的标签展示：
  - 上一版错误地把“当前选择的标签组合”显示在每篇结果卡片上。
  - 现在从内容集合生成 URL 到真实文章标签的映射，结果卡片只展示文章 frontmatter 中实际存在的标签。
- 首页 hero 和分区说明更新为更开放、更生活化的表达：
  - 不只强调志愿填报。
  - 明确包括专业学习、校园日常、衣食住行、城市体验和成长选择。
  - 鼓励短分享、避坑提醒和生活观察，不要求严肃长文。

## 设计取舍

- 本次不引入复杂筛选面板、作者筛选、日期筛选或实时联动搜索建议。
- 多标签采用“所有标签同时命中”的 AND 逻辑，选得越多结果范围越小，更符合精准定位的筛选直觉。
- 继续复用现有 Article frontmatter 和 Pagefind 索引，不新增内容字段。

## 验证

- 已运行 `npm run build`，Astro 构建、sitemap 和 Pagefind 索引均成功；Pagefind 输出显示已索引 1 个 filter。
- 已运行 `npm audit`，结果为 0 个漏洞。
- 已通过本地预览 `http://127.0.0.1:4322/` 检查首页文案渲染。
- 已通过 Playwright CLI 检查 `/search/`：
  - 单个标签筛选不再出现失败提示。
  - 多选两个标签后状态显示为“已选择 2 个标签”，并返回同时匹配所有已选标签的文章。
  - 多选结果卡片只显示文章自己的真实标签，不再把已选标签平铺到所有结果上。
  - 点击“清空”后恢复普通关键词搜索界面。
  - 浏览器控制台无 error。
