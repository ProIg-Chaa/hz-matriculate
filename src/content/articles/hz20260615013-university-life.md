一段真实的商科学习与实习体验

 适合读者 想了解商科真实情况的高中生

首先，在这里祝贺各位刚刚结束高考的学弟学妹们。你们现在大概正刷着手机，对大学生活充满期待。我下面要说的话可能不太好听，但在填志愿之前，有些东西你们有权先知道。

我先交代一下自己：华南农业大学会计学 ACCA 方向，大二在读，目前做了三段八大会计师事务所的实习，暑期和年审都体验过。不是什么大佬，就是一个刚摸清门道的过来人。

商科专业，跟你想象的不一样。

会计学课程本身其实不难。真正让人难受的，是这个圈子骨子里的社会达尔文主义，弱肉强食是明规则，没人会等你慢慢成长。我实习的时候亲眼见过前辈干活干进医院。专业课老师自己都坦白：非顶级院校走商科，路很长，也很累。说实话，审计是商科出来最可能拿到的最高薪资，但工作强度极高，时薪算下来低得离谱。就业方向集中在四大、八大、企业财务和金融中后台，薪资分化极大，同样毕业有人拿 8k，有人拿 25k——差距全在实习履历上，不在绩点上。商科一点也不轻松，它的社会化程度高到你需要提前三年开始卷。

再说我自己的选择。选 ACCA 方向班不是因为什么远见，其实就是学历崇拜。觉得华农的本科学历不够，想靠海外硕士补上，又不想吃考研的苦，想去外面看看，ACCA 恰好搭了这条桥。但跟你说句实话：如果你不走外贸、不进外企，这个证书性价比极低，根本没必要折腾。大二回头看，我不后悔走这条路，但我觉得你有权知道它值不值。

好了，来说真正重要的——实习。

大一的时候我跟你们一样，觉得实习是大三大四的事，什么都不会怎么实习？干过才知道，实习生就是干最基础的活，贴票、对账、整理底稿，是个人就能上手。企业录不录你，跟你是不是 985、211 没关系，只看那段时间缺不缺人。我大二到现在做了三段八大，只要敢投，就有机会。

但有一点得说清楚。走审计这一行，四大是外审的最高平台。如果你跟我一样不是 target school，校招直接投基本白给。真正好用的路是校园大使：门槛低得多，干好了直接拿面试直通卡，曲线救国。大二寒假之前搞定第一份实习，别被招聘要求吓到，投就是了。

第二件事：绩点和综测，趁早想清楚。

我自己每门课都想冲满绩，综测也卷到前列，后来跟多位 HR 聊过我才彻底信了——商科招聘不看绩点，看的是你有没有证、有没有真刀真枪干过活。企业只在乎培养你花多少成本、多长时间。一份实习加一张证，碾压满绩成绩单。如果你不追求国内保研和奖学金，这些东西真的屁用没有。

但这里有个前提：大二之前想清楚，你到底走就业还是升学。两条路的准备逻辑完全不同。我很早就定了走海外申硕或直接就业，大一大二几乎没上过校内课，全砸在实习和考证上。商科专业课不难，真正的成长在实务里。课该旷就旷，严的找代课，别被课表绑住。

第三件事：商赛，别太上头。

我自己参加过，说实话，离实际太远了。写方案、做 PPT、对着评委表演，跟真实商业完全是两个世界。面试的时候 HR 根本不追问，你熬夜熬出来的奖状在人家眼里约等于空气。小红书上随便一翻，全是劝人别盲目打比赛的帖子。唯一说商赛有用的人，基本都是低年级没实习经历、拿来充简历的，这恰恰说明它只是个不得已的替代品。当然，互联网+、挑战杯这类有硬核项目的竞赛另说，但纯商赛对会计审计方向就业没有任何意义。时间有限，优先实习。
最后一件事，也是最重要的——别跟技术脱节。

不是让你转码。是让你会用 AI Agent 工具。我现在日常就是终端里 Claude Code 加 WorkBuddy 双开，说几个真实的：用它审计过账龄分配工具，三分钟定位出一个隐藏的空循环 Bug 和 XSS 安全漏洞；设了自动化定时任务，每周自动抓 GitHub 高星项目整理报告。最绝的一次，leader 让我从三千七百多份合同里摘录关键条款，正常干至少两周。我把合同喂给 Claude Code，一天全搞完。我完全不懂代码，全程自然语言说需求。

商科的社会化程度本来就高，跟技术脱节等于自断一臂。会用 AI 工具的商科生和不会用的，已经是两种竞争力完全不同的人。现在就接触，别等到被人甩开再后悔。

最后说一句： 绩点只是入场券，实习才是定价权，而会不会用 AI，决定你还能不能留在这张桌子上。
