# 2026-06-12 问题与回答版块

## 背景

本次新增独立问答版块，用于集中展示高中生和应届生提出的问题，并把校友围绕某个问题的回答聚合到同一个问题详情页。目标是让读者不只浏览既有文章，也能从真实问题出发找到信息。

## 改动范围

- 新增 `questions` 内容集合，问题内容存放于 `src/content/questions/`。
- Article 内容模型新增分类 `问题回答`，并新增可选 `question` 字段用于关联问题 slug。
- 新增 `/questions/` 问题列表页和 `/questions/[slug]/` 问题详情页。
- 顶部导航新增“问答”，分类数据新增“问题回答”。
- 新增 2 个示例问题和 1 篇示例回答，用于验证“已回答”和“征集中”状态。
- README 补充问题与回答内容维护方式。

## 实现取舍

- 问题状态不写入 frontmatter，由关联回答数量自动推导：有回答显示“已回答”，无回答显示“征集中”。
- 回答仍复用现有文章模型、文章列表和文章详情页，不新增单独回答详情模板。
- 本次不做在线提问表单、后台审核、数据库或评论。
- 示例内容明确标注为示例，后续可替换为真实问题与回答。

## 验证

- 已运行 `npm run build`，Astro schema、sitemap 和 Pagefind 构建通过；本次构建输出 25 个页面。
- 已本地预览 `/questions/`，确认已回答问题显示 1 个回答，征集中问题显示 0 个回答。
- 已本地预览两个 `/questions/[slug]/` 详情页，确认有回答的问题能聚合回答文章，无回答的问题显示征集提示。
- 已检查 `/categories/question-answers/`，确认可列出“问题回答”类文章。
- 已检查 `/search/`，确认问题回答文章可被 Pagefind 搜索到，控制台无 error。
- 已运行 `npm audit`，结果为 0 个漏洞。
