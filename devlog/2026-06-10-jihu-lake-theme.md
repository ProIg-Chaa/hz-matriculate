# 2026-06-10 霁湖行舟品牌与浅暖色主题

## 背景

网站名暂定为“霁湖行舟”。经过湖蓝暗色、蔚蓝色等试色后，最终选择回到项目初版更接近纸面感的浅白黄色暖色调：温和、清晰、可信，更适合文章分享与经验资料库的阅读场景。

## 完成内容

- 默认站点名从“高中校友升学经验库”调整为“霁湖行舟”。
- 更新 `.env.example` 与 `README.md` 中的站点名。
- 全局色彩调整为：
  - 米白 / 浅黄背景；
  - 白色半透明内容面；
  - 深棕黑正文；
  - 柔和棕金强调色；
  - 浅黄色提示和免责声明。
- 保留 CSS-only 低饱和动态渐变背景，不新增粒子、Three.js、外部字体或其他运行时依赖。

## 重要取舍

- 品牌名改变不影响内容定位，项目仍然是校友升学经验资料库。
- 没有引入暗色主题或高饱和蓝色，避免削弱内容站的温和阅读气质。
- 没有新增主题切换，当前浅暖色作为默认视觉。
- 保留新版布局、卡片微交互、滚动淡入和 Pagefind 修复，只回调色彩系统。

- `npm run build` 通过，Astro、sitemap、Pagefind 均成功构建。
- `npm audit` 通过，结果为 0 vulnerabilities。
